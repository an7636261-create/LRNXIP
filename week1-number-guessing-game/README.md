# Number Guessing Game 🎯

**Learnix Python Internship — Week 1 Project**

## About the Project

The Number Guessing Game is a beginner-friendly console application developed using Python. The computer generates a random number between 1 and 100, and the player tries to guess the number within seven valid attempts.

The game provides hints to help the player guess the correct number.

## Features

- Generates a random number between 1 and 100.
- Allows the player seven valid attempts.
- Displays hints when the guess is too high or too low.
- Validates user input and handles invalid entries.
- Displays the number of attempts used when the player wins.
- Reveals the correct number if the player runs out of attempts.
- Allows the player to play multiple rounds.

## Technologies Used

- Python 3
- Python built-in `random` module

## How to Run the Project

1. Install Python 3 on your computer.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

   ```bash
   python main.py
   ```

   If your system uses `python3`, run `python3 main.py` instead.

## How to Play

1. Run the Python program.
2. Enter a whole number between 1 and 100.
3. Follow the hints displayed by the game.
4. Continue guessing until you find the correct number or use all seven valid attempts.
5. Choose whether to play another round.
